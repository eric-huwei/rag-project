# RAG 后端

## AI 配置

AI 密钥、服务地址和模型只从后端目录的 `.env` 文件读取。
首次使用时，复制 `.env.example` 为 `.env`，填写以下三项：

```dotenv
AI_API_KEY=新服务提供的密钥
AI_BASE_URL=新服务提供的接口地址
AI_MODEL=新服务提供的模型名称
```

此文件是后端 AI 配置的唯一来源。程序不会读取系统或终端中的同名环境变量，代码也没有地址、模型或密钥的备用值。
`.env.example` 仅供首次创建配置文件使用，不参与配置读取。

修改 `.env` 后重启后端即可生效，无需修改代码。
缺少任意一项时，AI 接口会提示需要填写的配置项，不会向外部 AI 服务发起请求。
`.env` 已加入 Git 忽略规则，请将真实密钥仅保存在本地文件中。
